How each hop is measured

SCO · phone ⇄ ESP32
App opens a Bluetooth SCO link to the ESP32 and plays a 1 kHz tone burst; the ESP32 loops its SCO input back; the app times the burst's return in its microphone stream. Includes Android audio-stack latency on both ends.
BLE · ESP32 ⇄ app
App writes a ping on the control characteristic; firmware answers with a pong notification. Pending until the GATT service ships.
WebSocket · app ⇄ server
App sends {"type":"ping"}; server echoes pong.
Est. one-way
Half the total round trip. Jitter buffers add on top of this in the real audio path.
